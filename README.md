# Cronograma-e-An-lise-Financeira-de-Viagem-Curitiba-Recife
Este projeto consiste em uma página interativa desenvolvida com o objetivo de apresentar, organizar e analisar os custos envolvidos em uma viagem de Curitiba para Recife. A aplicação converte dados de planilhas em visuais gráficos intuitivos para fácil interpretação orçamentária.
